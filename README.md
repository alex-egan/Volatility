# Volatility

A new build of the stock market bar software I have always been wanting to build. This time, it's for real.

## Description

The project consists of a .NET Web API, auto-generated API Client, and a Blazor WASM application for the UI. I intend to expand to a Firmware project as well to support operations for ticker boards and other live displays.
